# SchoolsFirst FCU (schoolsfirst)

SchoolsFirst Federal Credit Union is a federally chartered, member-owned credit union headquartered in Tustin, California, serving educators and their families. Founded in 1934, it is the largest credit union in California and one of the largest in the United States, with roughly $31.9 billion in assets and over 1.4 million members.

## APIs

SchoolsFirst FCU does not publish a first-party public developer program or API documentation. A probe of `developer.schoolsfirstfcu.org` fails to resolve, `/developers` returns HTTP 404, and the `api.schoolsfirstfcu.org` host is the member online-banking login backend (it redirects to `/member-login/login`), not a documented API surface.

Consumer-permissioned account and transaction data is reachable only through US open-finance aggregators — Plaid, Finicity, MX, and Akoya — rather than a direct SchoolsFirst API. No public Financial Data Exchange (FDX) participation or CFPB Section 1033 (Personal Financial Data Rights) data-access posture is documented at this time. This is the honest, non-fabricated posture for the institution: identity only, aggregator-only access.
